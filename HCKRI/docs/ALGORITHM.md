# 算法实际流程

## 数据与表征

1. 读取CSV并规范化标签、攻击类型、来源和排序字段；根据配置把原始类型映射到正常类0与风险类1-4。
2. 将`unknown_attack_types`列出的类型整体留至测试集。已知数据按训练65%、验证15%、测试20%划分；PSAD推荐配置按`time`中的原始行事件标识分组，防止来源副本跨集合。
3. 只用训练记录拟合数值均值、标准差和字段类型。数值字段归一化并哈希到数值分区；离散字段使用稳定哈希编码。标签和指定排除字段不作输入。
4. 在各划分内部排序并构建窗口，默认长度12、步长3。窗口标签和未知标记按`data.py`实现聚合，不等于原始记录数量。
5. 仅对已知训练窗口分层选择30%作为有标签数据，其余用于伪标签训练。

这是统一事件序列编码，不是通用传感器重采样平台。TON/Edge网络CSV按特征拆成多视图时，不应宣称已经采集并对齐网络、主机和遥测三种独立物理来源。PSAD的`time`是预处理产生的原始行标识，也不是已经核实的真实攻击会话标识。

## 网络

输入特征与来源嵌入拼接并投影到64维，经过3/5/7并行一维卷积及残差归一化，得到局部表征；单层双向LSTM提取时序表征，经来源上下文门控后送入2层、4头Transformer。三个阶段分别做注意力与均值池化，拼接后经MLP融合，输出64维表征和5类logits。

本版本`_stage_fusion`实际是拼接加MLP。返回的三个阶段权重是均匀占位值，不是学习得到的阶段注意力，不能把它作为可解释性证据。

## 学习与推理

- 有标签窗口使用交叉熵；无标签窗口仅当最大Softmax概率达到伪标签阈值时进入伪标签交叉熵。
- 原型对比损失使用归一化表征与原型的余弦相似度，温度0.20。每轮结束后用有标签训练表征更新原型；当前实现不把伪标签加入原型中心。
- 原型含正常类（若有有标签正常样本），初始不可用。距离门限为类内训练表征到中心欧氏距离的95%分位数加0.02。
- 最大Softmax置信度低于0.55，或表征远离最近可用原型时，置未知标记。
- 风险分数为5类概率与等距严重度权重0、0.25、0.50、0.75、1的加权和。
- 在已知验证集上搜索4个递增分级阈值并按风险类宏平均F1选择检查点。8轮后恢复最佳检查点，用训练数据重建原型，再生成测试预测。
- 当前五分类决策会把未知标记窗口提升至最高风险类4；并未创建第6个未知类别。这种策略与“未知类型被正确分类”不是同一任务。

## 统一入口中的消融

| 变体 | 实际变化 |
| --- | --- |
| Full | `MultiSourceRiskNet`原始前向 |
| A / B / C | 分别去CNN / Bi-LSTM / Transformer |
| D / E / F | 分别去CNN+Bi-LSTM / Bi-LSTM+Transformer / CNN+Transformer |
| G | 去三主干，保留输入相关的浅层读出；不同于旧版常数输出G |
| H | 去原型库及依赖原型的对比项，保留低置信度未知判定 |
| I | 仅关闭原型对比损失 |
| J | 仅关闭伪标签损失 |
| K | 将卷积核3/5/7改为5/5/5，保留三个分支 |
| L | 去CNN输入残差 |
| M | 将来源门控设为常数1 |
| N | 去额外来源上下文，保留输入来源嵌入 |

N不等于去多阶段融合。历史`MechanismRiskNet`另有`Final-Stage-Only`控制，且其Full实现不同，使用时须明确区分。旧A-G脚本只作为历史入口保留，推荐统一入口使用`ComparisonAblationNet`。
