# 公开前检查

- 本包没有自动上传GitHub，也没有修改旧实验结果。
- 请确定作者、仓库介绍、论文最终题目与引用信息；未确认的信息没有擅自填入。
- 请确认导师/单位允许公开，并检查合作者与第三方代码权利。
- 未代作者选择MIT、Apache等许可证。没有许可证不等于已授予通用开源使用权；选择后在仓库根目录加入适用的LICENSE。
- 不上传原始数据、checkpoint、predictions、`.env`、SSH配置、虚拟环境、Word论文、审稿意见及运行日志。
- 使用GitHub网页上传时，`.gitignore`不能拦截你手动选择的文件；应上传本发布包内容，不要上传原工作区。
- 后续新增代码或数据后需要重新检查。发布包扫描只覆盖打包时的文件，不能保证所有未来内容安全。
- 首次公开后可创建版本标签并归档代码版本；公开仓库名称可设为`HCKRI`。
